## Ручная проверка через UI (≈3 минуты)
1. Откройте `http://localhost:8000`, войдите как `client1`.
2. «Новая заявка» → продукт «Оборотный кредит» → сумма 1 200 000, срок 24, цель любая.
3. Компания: нажмите на ИНН `7701000019` в списке тестовых → «Найти в реестре»; роль — «Собственник».
4. Финансы: 24000000 / 3600000 / 40000. Шаг 5: согласие → «Отправить в банк».
5. Наблюдайте, как этапы сменяются сами; затем «Принять предложение» → «Подписать договор» → «Деньги выданы».
6. Войдите как `underwriter` (другая вкладка/окно): откройте заявку, посмотрите данные источников и скоринг. Для ручной ветки повторите заявку с сценарием 3 или 4 от `client3`/`client1`.
